◆ permanent_release_no_motion_frames

int glim::DynamicClusterExtractorParams::permanent_release_no_motion_frames

PERMANENT_DYNAMIC track whose cluster shows no motion of its own for this many matched frames is released: the track has been handed over to static structure. With locked_struct_frac > 0 "no own motion" = the cluster lies on static structure; otherwise = no free space and no strong voxel motion. 0 = off. Default: 3

◆ use_obb

bool glim::DynamicClusterExtractorParams::use_obb

Track-level evidence accumulation: e <- decay*e + (frame_evidence - bias), confirmed when e >= on (on <= 0 = off). Yaw-oriented boxes (XY PCA) for elongated clusters with >= obb_min_points, eigenvalue ratio >= obb_min_elongation, used only if the OBB footprint < obb_max_area_ratio * AABB footprint.
