double glim::DynamicObjectRejectionParamsCPU::locked_struct_frac

Locked-dynamic cluster whose points lie for at least this fraction on static structure (free-space map cells occupied for struct_min_age frames and not known free since) is not removed and reports no own motion, so the tracker can release it (0 = off).
